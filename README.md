Notes:
We represent physical 32-bit wires with the normal integer;
    any operation on said integers can use bitwise functions, for loops, etc

Logic gates will be used iff the physical hardware would be present
    any code that that does an action that otherwise would not exist physically
    (for loops, bit shifting, storing results, etc) will not use logic gates

Bus is defined as an typical Integer
Registers are defined as typical Integers
